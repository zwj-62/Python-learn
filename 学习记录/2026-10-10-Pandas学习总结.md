## 优先巩固的地方

### 1. 区分“返回处理结果”与“修改变量中的数据”

当前这些语句调用了方法，但没有把返回结果保存下来：

```python
df.fillna('安徽')
df.drop_duplicates(subset=['订单号'], keep='first')
df.drop(df[df['单价'] < 0].index)
```

默认情况下，它们返回一个处理后的对象，原来的 `df` 保持原样。课堂单独观察某个方法的结果时可以这样写；要把它接入后续处理流程，需要保存结果，例如：

```python
df = df.drop_duplicates(subset=['订单号'], keep='first')
```

`sort_values()` 默认也需要保存返回结果，后续才会使用排序后的数据。若选择 `inplace=True` 的方式，不要再把方法返回值赋给 `df`，因为这类调用会返回 `None`。参见 [fillna](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.fillna.html)、[drop_duplicates](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.drop_duplicates.html) 和 [sort_values](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.sort_values.html) 官方说明。

Notebook 中目前把许多表达式放在同一个代码单元中，常规执行只自动展示最后一个表达式的结果。建议按“读取、缺失、重复、异常、格式、统计”拆开单元，并观察每一步的行数和异常数量。

### 2. 清洗先定义规则，再选择方法

- **城市缺失：** 演示 `fillna('安徽')` 可以观察填充值效果；实际城市未知时不能推断它属于安徽。可以按练习约定填“未知城市”，并只针对城市这一列处理。
- **负数：** `abs()` 的调用有效，但能否取绝对值取决于业务含义。若负数代表退款或退货，应按退款规则处理；若练习明确只统计正常正向销售，可排除单价或数量非正的记录。
- **订单重复：** 只有明确“一条订单对应一行”时，才适合直接按订单号去重。若一个订单有多件商品，订单号重复可能是正常情况，需要用更合适的字段判断。
- **前后填充：** `ffill()`、`bfill()` 需要相邻记录之间存在可解释的关系；不同客户的城市不能仅因相邻就相互填充。

当前数据还存在一条负销售数量，你的笔记只对负单价进行了赋值处理。完成综合练习时，应同时核查数量和单价。

### 3. 日期文本统一与日期类型转换是两个步骤

你写的替换语句正确地统一了分隔符，但结果仍是字符串。若下一步要按日期范围筛选、计算时间间隔或提取月份，可以进一步转换：

```python
df['订单日期'] = pd.to_datetime(df['订单日期'], format='%Y-%m-%d')
```

这一步放在分隔符统一之后。它属于适合接下来补充的知识，不把尚未学习的类型转换视为当前课堂演示写错。参见 [to_datetime 官方说明](https://pandas.pydata.org/docs/reference/api/pandas.to_datetime.html)。

### 4. 明确分组统计使用的是哪份数据

排序与分组笔记中的 `pd.read_csv(..., nrows=50)` 只读取前 50 行，并重新建立了一个 `df`。另一份 Notebook 内存中做过的清洗不会自动写回 CSV。

实际项目应让分组统计接收清洗后的 DataFrame，或者明确读取清洗后导出的文件。否则缺失、重复和负数仍可能进入统计。

你当前用 `groupby('产品类别')['订单号'].count()` 统计订单，在订单号不缺失且一行一单的前提下成立。补充区别：`count()` 不计被统计列中的缺失值；`size()` 统计每组行数。当前文件订单号没有缺失，这一点不会造成当前结果误差。

### 5. 几个小的笔记修正

- `.min()` 前的注释应写“最低单价”，当前误写成“最高”。
- `keep=False` 中的 `False` 是布尔值，注意注释里的 `Flase` 拼写。
- `.duplicated()` 默认只将后续重复项标为 `True`。要找出重复组中的所有记录，使用 `keep=False`；要查看具体记录，再用布尔结果筛选原表。
