# Python-learn
个人Python学习练习仓库

## 📖 项目内容
- Python基础语法：循环、函数、数据容器、面向对象、异常处理
- 数值计算：NumPy
- 数据分析：Pandas
- AI开发：大模型API调用、AI交互机器人实验
- 可视化：Streamlit 交互式网页应用
- Jupyter Notebook 数据分析演示

## 📁 目录结构
- 第一章~第六章：分章节Python基础练习代码
- resources：案例配套资源（图片、文本）
- sessions：AI对话实验记录

## 🛠 运行环境
Python 3.11.9
主要依赖：numpy, pandas, streamlit
